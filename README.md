# academic-performance-analytics
Comprehensive data analysis project in R covering data cleaning, custom scholarship calculation logic, data visualization (ggplot2), statistical distribution fitting, and linear regression modeling.

## 📋 Project Overview
The goal of this project was to analyze a dataset of students to identify patterns between fields of study, gender, study time, and academic results. Key highlights include:
- **Data Cleaning**: Handling missing values using mean imputation and mode replacement.
- **Custom Logic**: Implementing a scholarship calculation engine based on specific GPA thresholds.
- **Data Visualization**: Advanced plots using `ggplot2` to explore demographic distributions and study habits.
- **Statistical Analysis**: Distribution fitting for study time and normality testing (Shapiro-Wilk).
- **Linear Regression**: Modeling the relationship between study hours and GPA for specific departments.

## 🛠️ Tech Stack
- **Language**: R
- **Key Libraries**: 
  - `readxl` (Data import)
  - `Hmisc` (Data imputation)
  - `ggplot2` (Visualization)
  - `fitdistrplus` (Distribution fitting)
  - `RVAideMemoire` (Statistical utilities)
